# Zonda (web)

Página de descarga de Zonda para Windows. Este repositorio solo tiene los archivos publicados: el instalador, `version.txt` y `relays.txt` (lista de relays Nostr firmada por el fundador), que las versiones anteriores de la app leen. El código fuente está en https://github.com/nicoconvoz/zonda-go (AGPL-3.0).
